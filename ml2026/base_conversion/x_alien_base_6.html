Solution

Each symbol represents a number between 0 and 5. Each position represents a power of 6. The total value is found by adding up the products of each symbol’s value times its corresponding power of 6.

\[4\cdot 6^{5}+3\cdot 6^{4}+1\cdot 6^{3}+0\cdot 6^{2}+2\cdot 6^{1}+5\cdot 6^{0}\]
