Solution

You should be able to complete the picture. Use symmetry to complete the parabola, and use the slope to extend the line.


The intersection further left is at \(x_1=0\) and it is an extraneous solution.

The intersection further right is at \(x_2=8\) and it is an extraneous solution.

I’ll also mention that you could solve approach this problem algebraically. First, examine curve \(y=f(x)\) to find the transformations. From those transformations, you can write an algebraic definition of \(f(x)\).

\[f(x)=-4+2\sqrt{x+1}\]

To write an algebraic definition of \(L(x)\), use point-slope form.

\[L(x)=\frac{-1}{2}(x-4)-8\]

Then set up the equation to solve.

\[-4+2\sqrt{x+1}=\frac{-1}{2}(x-4)-8\]

By doing the algebraic manipulations, you’ll find two possible solutions: \(x_1=0\) and \(x_2=8\). If you test each in the equation, you’ll find that \(x=0\) is an extraneous solution, and \(x=8\) is an extraneous solution.
