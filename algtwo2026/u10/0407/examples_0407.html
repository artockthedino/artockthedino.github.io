Let function \(f\) represent a cubic polynomial function with integer coefficients.

\[f(x)~=~ax^3+bx^2+cx+d\]

That function has a real root \(x=\frac{-7}{8}\) and a complex root \(x=7-2i\).

\[f\left(\frac{-7}{8}\right)~=~0\] \[f(7-2i)~=~0\]

When a polynomial with real coefficients has complex roots, they always come as complex-conjugate pairs. Thus, we know all three factors.

\[f(x)~=~({8}x+{7})(x-(7-2i))(x-(7+2i))\]

Distribute subtraction across inner parentheses.

\[f(x)~=~({8}x+{7})(x-7+2i)(x-7-2i)\]

Multiply the two complex-root factors using a box.


Notice some of those terms cancel.

\[f(x)~=~({8}x+{7})(x^2-14x+49-4i^2)\]

Remember that \(i^2=-1\).

\[f(x)~=~({8}x+{7})(x^2-14x+49-4(-1))\]

\[f(x)~=~({8}x+{7})(x^2-14x+49+4)\]

\[f(x)~=~({8}x+{7})(x^2-14x+53)\]
