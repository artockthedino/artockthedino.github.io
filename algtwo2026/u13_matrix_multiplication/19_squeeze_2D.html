Question

A video-game developer is hoping to apply a squeeze map to a set of points by using matrix multiplication. Interestingly, during a squeeze map, the area remains constant.


The starting points are stored as rows in a 5 \(\times\) 2 matrix \(S\).

\[S=\begin{bmatrix} -5.161 & -3.999\\ 5.744 & 3.705\\ 5.803 & -1.704\\ 1.053 & 4.113\\ -5.072 & 3.766 \end{bmatrix}\]

The squeeze matrix can be found by using \(k=0.635\) in the formula below.

\[T~=~\begin{bmatrix} k & 0\\ 0 & 1/k \end{bmatrix}\]

The final points (in matrix \(F\)) are found by multiplying \(S\cdot T\).

\[F=S\cdot T\]

That multiplication can be done using the diagram below.


What is the new y coordinate when point \((5.744, 3.705)\) undergoes the squeeze transformation with \(k=0.635\)?

Solution

The squeeze transformation matrix:

\[T=\begin{bmatrix} 0.635 & 0\\ 0 & 1.5748031496063 \end{bmatrix}\]

We are looking for the new y coordinate after point \((5.744, 3.705)\) undergoes the squeeze mapping. Use column 2 of \(T\):

\[(5.744)(0)~+~(3.705)(1.5748031)\]

The new y coordinate is 5.8346457.
